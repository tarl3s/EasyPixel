## EasyPixel v0.3.1

**Open many files at once**
In **File → Open**, select several files (hold Ctrl or Shift) and each one opens in its own tab.

**Fixes**
- Opening a PNG, GIF or Piskel file no longer leaves the palette panel empty (and the palette no longer seems to
  vanish when switching tabs): those pictures get your starting palette to pick colours from.
- Colours in `.epx` files are now written in the usual RRGGBBAA order. Before, EasyPixel itself read them right, but
  other tools (scripts, game importers) saw red and blue swapped. Older `.epx` files still open with the right colours;
  files saved with this version need EasyPixel 0.3.1 or newer.

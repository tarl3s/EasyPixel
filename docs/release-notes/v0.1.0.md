## EasyPixel v0.1.0 — first release

EasyPixel is a free pixel-art editor for Windows. Download `EasyPixel-win-x64.zip`, unzip it, and open `EasyPixel.exe`. Nothing else to install.

**What you can do**

- Draw with a full set of tools: pencil, eraser, bucket, line, rectangle, ellipse, shading, lighten / darken, dither, spray, eyedropper, and mirror drawing.
- Select, move, cut, copy and paste with rectangle, ellipse, lasso and magic wand.
- Work with layers and groups (opacity, blend modes, lock, hide).
- Animate: frames with their own speed, a timeline, tags, onion skin and a preview window.
- Use any canvas size, in full colour or with a palette (like Aseprite).
- Open and save `.aseprite`, `.piskel` and EasyPixel's own `.epx`; open PNG, GIF and sprite sheets.
- Export PNG, animated GIF and sprite sheets.
- Use it in 9 languages, with a dark or a light theme.

**With EasyEngine**

- File → Import sprite from EasyEngine… edits a sprite from your game.
- File → Export to EasyEngine sends your sprite back; in EasyEngine's Animations window, press **Import from EasyPixel**.

**Updates:** EasyPixel checks for new versions when it starts and asks before downloading anything. You can turn this off in Edit → Settings.

Windows may warn that the app isn't signed yet: click **More info → Run anyway**.
